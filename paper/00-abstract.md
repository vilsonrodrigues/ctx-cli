# SPACE: Self-Partitioned Agent Context Environment for Lifelong Learning Agents

## Abstract

Language model agents increasingly rely on test-time reasoning to solve complex tasks, yet existing approaches suffer from uncontrolled context growth, implicit reasoning states, and poor separation between exploration and decision-making. We introduce **SPACE (Self-Partitioned Agent Context Environment)**, a training-free architecture that structures test-time computation through irreversible deliberation cycles and ephemeral workspaces. SPACE implements a three-tier memory hierarchy grounded in Tulving's cognitive taxonomy: ephemeral *working memory* (cleared on scope exit), persistent *episodic memory* (scope-local notes), and global *semantic memory* (insights persisting across sessions). A layered hub-and-spoke navigation topology enforces cognitive discipline: agents branch from a stable `main` context into isolated scopes for subtasks, returning only synthesized conclusions—transforming test-time compute from unstructured token expenditure into explicit, bounded deliberation. A project-based session management mechanism enables cross-session knowledge transfer: when new projects begin, insights persist universally while working memory resets, and previous scopes remain accessible via `@project` notation. Unlike learned compression approaches (Context-Folding, AgentFold, CaT) requiring task-specific training, or graph-based methods permitting arbitrary navigation, SPACE enforces strict transition rules that prevent reentry, nesting, or unbounded exploration. Evaluation on SWE-Bench-CL and LifelongAgentBench demonstrates that SPACE maintains bounded context growth ($O(k_{\max})$) independent of task count, while linear baselines exhibit $O(T)$ accumulation. The primary contribution is **operational stability**: SPACE enables agents to operate across extended task sequences and multiple sessions without performance degradation, validating explicit context management as a principled framework for scalable test-time reasoning in lifelong learning agents.
