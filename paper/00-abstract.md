# Abstract

Long-running language model agents face a fundamental limitation: context windows are finite, but tasks can require unbounded reasoning. As agents execute multi-step tasks, their context grows linearly with each message, eventually exceeding model limits or degrading performance through attention dilution. Current approaches address this through learned compression—Context-Folding uses reinforcement learning, AgentFold and CaT require supervised fine-tuning on thousands of trajectories—adding significant complexity and limiting portability across models.

We introduce **Explicit Context Management (ECM)**, a training-free approach that treats conversation context as versioned state. Our method provides agents with a minimal command interface—navigation (`scope`, `goto`), persistence (`note`, `insight`), and inspection (`notes`, `insights`, `status`)—enabling deliberate control over what information persists across reasoning steps. Unlike stack-based approaches (Context-Folding's `branch/return`), ECM implements **graph-based scope navigation** where agents can freely traverse between any existing scopes.

The architecture implements a **three-tier memory system**: ephemeral working memory (messages in current scope), persistent episodic memory (scope-local notes), and persistent semantic memory (global insights). This distinction enables knowledge transfer patterns impossible with pure compression: insights discovered in one scope become immediately available across all scopes without explicit retrieval.

We evaluate our approach on sequential coding tasks from SWE-Bench-CL, comparing against linear conversation baselines. Results show **88% reduction in peak context** (12,059 → 1,402 tokens) and **34% faster execution** while maintaining solution quality—comparable to learned approaches but without training overhead. For isolated tasks, linear approaches remain more efficient, revealing that explicit context management provides value specifically when context accumulates across multiple related steps.

The approach requires **no model fine-tuning, no reinforcement learning**, and integrates with any tool-use capable model (GPT-4, Claude, Gemini, open-source). Our open-source implementation demonstrates that effective context management for long-running agents can be achieved through simple, explicit mechanisms rather than learned compression.
