# SPACE: Self-Partitioned Agent Context Environment for Lifelong Learning Agents

## Abstract

Large Language Models (LLMs) exhibit strong reasoning capabilities when provided with sufficient context, yet they fundamentally lack persistent, structured memory. As interaction length grows, models face context saturation, reasoning drift, and loss of alignment with prior decisions. Existing approaches typically rely on expanding context windows, retrieval-augmented generation, or learned compression policies, but these methods often conflate *reasoning history* with *knowledge retention*, leading to inefficiencies and instability during long-horizon tasks.

We introduce **SPACE (Self-Partitioned Agent Context Environment)**, a training-free cognitive runtime architecture that structures test-time computation through irreversible deliberation cycles and ephemeral workspaces. SPACE organizes reasoning into disposable scopes for exploration and a persistent central context for decision consolidation, while maintaining a global semantic layer that shapes behavior across tasks and sessions. The architecture implements a three-tier memory hierarchy grounded in Tulving's cognitive taxonomy: ephemeral *working memory* (cleared on scope exit), persistent *episodic memory* (scope-local notes), and global *semantic memory* (insights). A complementary project-based session management mechanism enables cross-session episodic retrieval via `@project` notation while insights persist universally.

Unlike graph-based or chain-of-thought methods that treat test-time compute as implicit token expenditure, SPACE enforces strict transition rules—preventing reentry, nesting, or arbitrary navigation—that yield predictable compute usage and stable long-term behavior. Evaluation on SWE-Bench-CL and LifelongAgentBench demonstrates that SPACE maintains bounded context growth ($O(k_{\max})$) independent of task count, while linear baselines exhibit $O(T)$ accumulation. We demonstrate how SPACE enables structured planning, alternative exploration, and cross-session learning without context saturation, positioning it as a principled framework for scalable test-time reasoning in LLM-based agents.
