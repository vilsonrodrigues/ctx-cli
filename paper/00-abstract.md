# SPACE: Self-Partitioned Agent Context Environment for Long-Horizon Agents

## Abstract

Large Language Model (LLM) agents struggle with long-horizon tasks due to the linear accumulation of context, which increases latency, cost, and the probability of hallucination ("lost-in-the-middle" phenomenon). Existing solutions typically rely on learned context compression (e.g., Context-Folding) or extensive fine-tuning (e.g., AgentFold), which limits generalizability and imposes significant training overhead. We introduce **SPACE** (Self-Partitioned Agent Context Environment), a training-free architecture that enables agents to explicitly manage their context window via a three-tier memory hierarchy: ephemeral *working memory* (scopes), persistent *episodic memory* (notes), and global *semantic memory* (insights). By enforcing a radial navigation topology—where agents create temporary workspaces for subtasks and return only synthesized conclusions to the main context—SPACE effectively transforms the context management problem into a tool-use task. Evaluation on **SWE-Bench-CL** (15 sequential coding tasks) demonstrates that SPACE achieves an **88% reduction in peak context usage** (12,059 $\rightarrow$ 1,402 tokens) and a **34% reduction in execution time** compared to linear baselines. Crucially, SPACE exhibits **$O(1)$ context growth** for sequential tasks, whereas standard approaches scale as $O(n)$, validating explicit context management as a scalable paradigm for lifelong learning agents without requiring model architectural changes.
