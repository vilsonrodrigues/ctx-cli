# SPACE: Self-Partitioned Agent Context Environment for Long-Horizon Agents

## Abstract

Large Language Model (LLM) agents struggle with long-horizon tasks due to the linear accumulation of context, which increases latency, cost, and the probability of hallucination ("lost-in-the-middle" phenomenon). Existing solutions typically rely on learned context compression (e.g., Context-Folding) or extensive fine-tuning (e.g., AgentFold), which limits generalizability and imposes significant training overhead. We introduce **SPACE** (Self-Partitioned Agent Context Environment), a training-free architecture that enables agents to explicitly manage their context window via a three-tier memory hierarchy: ephemeral *working memory* (scopes), persistent *episodic memory* (notes), and global *semantic memory* (insights). By enforcing a radial navigation topology—where agents create temporary workspaces for subtasks and return only synthesized conclusions to the main context—SPACE effectively transforms the context management problem into a tool-use task. Evaluation on **SWE-Bench-CL** (15 sequential coding tasks) demonstrates that SPACE maintains a **constant-time $O(1)$ context window**, whereas linear baselines degrade into $O(n)$ accumulation. While this results in an 88% token reduction, the primary contribution is **stability**: SPACE enables agents to operate indefinitely without the performance degradation or context overflow inherent to linear architectures, validating explicit context management as a scalable paradigm for lifelong learning agents.
